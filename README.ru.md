# 🔍 FactCheck Bot — Telegram-бот для проверки новостей

Telegram-бот, который проверяет достоверность новостей и утверждений с помощью поиска в интернете и NLI-модели (Natural Language Inference). Пользователь присылает утверждение — бот ищет источники, сравнивает их с текстом и выдаёт вердикт с ссылками.

## 📌 Демо

> Пользователь: *"Илон Маск купил Twitter"*
> Бот: ✅ Утверждение подтверждается
> Источники: BBC News, The Washington Post

## 🎯 Мотивация проекта

Дезинформация — одна из ключевых проблем цифровой среды. Цель проекта — показать, что базовая проверка фактов может быть автоматизирована с использованием открытых NLP-моделей, без необходимости в дорогостоящих проприетарных решениях.

## 🏗️ Архитектура

```
Пользователь → Telegram-бот
                    ↓
         Поиск источников (DuckDuckGo, RU + EN запросы)
                    ↓
         Фильтрация по whitelist доверенных доменов
                    ↓
         Перевод (RU → EN) + NLI-анализ (facebook/bart-large-mnli)
                    ↓
         Confidence threshold + голосование по источникам
                    ↓
         Финальный вердикт + ссылки на источники → пользователь
```

## 🧠 ML-часть: что было исследовано

Один из ключевых вопросов проекта — как заставить NLI-модель, обученную на английском языке, надёжно работать с русскоязычными новостями. Были протестированы и сравнены два подхода:

| Подход | Точность (34 примера) |
|---|---|
| Multilingual модель напрямую (`mDeBERTa-v3-base-mnli-xnli`) | 76.5% |
| Перевод (RU→EN) + специализированная модель (`bart-large-mnli`) | **85.3%** |

**Ключевая находка**: обе модели показали систематическую слабость на классе `neutral` (не связанные утверждения) — модель склонна интерпретировать "разные факты на одну тему" как логическое противоречие. Гипотеза о том, что причина — в языке, была проверена и **опровергнута**: перевод текста на английский не устранил проблему с neutral-классом, значит, это ограничение самой архитектуры NLI-моделей, а не языковой барьер.

Решение: добавлен **confidence threshold** — если уверенность модели в топовом классе ниже порога (0.9), результат по умолчанию считается `neutral`. Это подняло точность с 60% до 85.3% на тестовом наборе.

## 🛠️ Технологический стек

- **Python 3.12+**
- `python-telegram-bot` — интерфейс бота
- `duckduckgo-search` — поиск источников (RU + EN запросы)
- `transformers` (Hugging Face) — NLI-модель
- `torch` (PyTorch) — вычисления модели
- `deep-translator` — перевод текста RU → EN
- `python-dotenv` — безопасное хранение токенов

## 📂 Структура проекта

```
├── bot.py                 # точка входа, Telegram-обработчики
├── check_claim.py         # логика проверки утверждения (поиск + анализ + голосование)
├── fact_checker.py        # низкоуровневые функции: модель, перевод, поиск, whitelist
├── test_data.py           # тестовый датасет (34 размеченных примера)
├── .env                   # токены (не публикуется, см. .gitignore)
├── .gitignore
└── requirements.txt
```

## 🚀 Установка и запуск

1. Клонируй репозиторий:
```bash
git clone https://github.com/ТВОЙ_USERNAME/factcheck-bot.git
cd factcheck-bot
```

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Создай файл `.env` в корне проекта:
```
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
```

4. Запусти бота:
```bash
python bot.py
```
